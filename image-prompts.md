## How to generate

1. Open [Google AI Studio](https://aistudio.google.com/) → select **Nano Banana 2** (image generation, Gemini 3.1 Flash Image).
2. Paste the style spec + one movement prompt at a time.
3. Save the output as `img/01.png`, `img/02.png`, etc.
4. Refresh the dashboard. Images replace the calligraphy automatically.

Or batch all 15 in a single Google AI Studio session — same style spec, just iterate the movement prompt.
